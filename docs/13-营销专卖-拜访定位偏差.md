# 营销专卖 · 拜访定位偏差

页面：`/marketing-monopoly/visit-location`，与扣款户名不符并列。

## 查询口径

- 来源为营销有效拜访（`visit_status='03'`、`deleted='0'`），最早日期 2024-01-01。
- 按 `cust_code=lic_no` 关联许可证，按客户经理 UUID 关联人员；遵循原 SQL，许可证覆盖全部状态。
- 使用 `ST_Distance_Sphere(longitude, latitude, gis_long, gis_lat)`，严格筛选原始距离大于阈值的记录，默认 200 米。
- 日期包含结束日。距离显示两位小数，筛选和导出保留原始精度。无可计算距离的记录不会命中条件。
- 球面距离直接使用两个系统的原始坐标；若系统坐标系不同，应另行确认转换口径。

## 页面功能

发证机关下拉列表统一与“扣款户名不符”使用同一字典，来源为有效许可证（`lic_status='10'`）中的机关。字典口径独立于拜访明细关联范围。

机关名称使用简称色彩标签，省略“天津市”和“烟草专卖局”，悬停显示全称。两组经纬度分别合并为两行位置列，距离列在常用桌面宽度可见；窄屏允许横向滚动。Excel 保留完整名称和独立经纬度字段。查询成功且总数为零时在表格内显示“暂未查到符合条件的数据”。市区各局简称统一为“市区第一”“市区第二”“市区第三”等。

发证机关多选、许可证号精确查询、客户名称包含查询；拜访日期默认过去一个月，支持一个月、三个月、半年、一年快捷范围。距离可选 100、150、200、250、300、500 米。

展示发证机关、客户经理、日期、许可证号、客户名称、两组经纬度、距离；支持日期、机关、距离排序，分页、首页缓存及 Excel 导出。原始 SQL 的 500 条限制改为分页，导出沿用 100000 条上限。

接口：`POST /api/marketing-monopoly/visit-location`，导出追加 `/export`，均要求登录。参数在日期、机关与客户筛选基础上增加 `distance_meters`。
