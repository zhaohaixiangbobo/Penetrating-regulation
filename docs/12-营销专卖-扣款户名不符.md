# 营销专卖 · 扣款户名不符

用途：记录营销系统扣款账号户名与专卖许可证持证人信息核对的业务口径、接口及验收方式。

## 菜单与页面

- 一级模块：**营销专卖**，与“营销审计”并列。
- 子模块简称：**扣款户名不符**。
- 页面地址：`/marketing-monopoly/bank-owner-mismatch`。
- 模块根路径 `/marketing-monopoly` 自动跳转到此页面。
- 页面说明：营销系统最新扣款账号户名与有效许可证持证人姓名不一致。

## 业务口径

1. 绑卡数据来自 `pc_pay_custbank`，按 `cust_code` 分组，以 `sysupdatedt DESC` 取最新一条。
2. 更新时间相同时，以已核对存在的 `custbank_uuid DESC` 作稳定次级排序；该标识只用于同时间记录的确定性选择，不表示业务生效先后。
3. 许可证来自 `r_license_info`，限定 `lic_status = '10'`。
4. 通过 `lic_no = cust_code` 关联，以 `manager_name` 与最新 `bankcard_owner` 去除两端空格后比较。
5. 最新绑卡户名为 NULL、空字符串或纯空格时排除。最新记录姓名一致时，即使旧记录不符，也通过规则。
6. `manager_name` 为 NULL 时，按提供 SQL 的比较语义排除；持证人信息缺失可另设完整性规则。
7. 当前按提供 SQL 的 `manager_name` 字段比对。法人另列字段、联合持证人、别名等扩展需要相应数据字段和匹配规则。
8. 绑定日期筛选作用于已经选出的最新记录，保留最新状态语义。

## 页面功能

| 功能 | 行为 |
| --- | --- |
| 发证机关 | 专卖表字典、多选、全选、清空；留空查全部 |
| 许可证号 | 完整号码精确查询，去掉输入两端空格 |
| 客户名称 | 包含文字查询，百分号和下划线按普通字符处理 |
| 绑定日期 | 默认展开；支持过去一个月、三个月、半年、一年；可选起止日期，覆盖结束日；留空查全部日期 |
| 查询 | 点击查询后加载，筛选提交回第一页 |
| 状态提示 | 分别展示尚未查询、查询中、无匹配记录与请求失败；空结果提示可清空绑定日期重查 |
| 重置 | 清空筛选、已提交状态、结果和本页缓存 |
| 排序 | 绑定时间、许可证号、发证机关；默认绑定时间倒序 |
| 分页 | 默认 20 条，每页最多 200 条 |
| 缓存 | 仅第一页，按用户名隔离，保留条件、排序和每页条数，1 小时有效 |
| 导出 | 同一提交条件和当前排序，最多 100000 条，达到上限提示缩小范围 |

展示字段：发证机关、许可证号、客户名称、持证人、绑卡持卡人、绑定时间。Excel 另包含发证机关代码，便于核对。

发证机关代码独立于营销公司代码，字典来自有效许可证的 `issue_org_code/issue_org_name`。当前模块继承登录校验，机关多选属于查询条件；用户与机关的授权映射需跟随项目权限方案接入。

## 接口

所有接口要求登录。

| 方法 | 地址 | 返回 |
| --- | --- | --- |
| GET | `/api/marketing-monopoly/issuing-organizations` | `issue_org_code/issue_org_name` 数组 |
| POST | `/api/marketing-monopoly/bank-owner-mismatch` | `total/page/page_size/items` |
| POST | `/api/marketing-monopoly/bank-owner-mismatch/export` | 与分页相同类型的行数组 |

查询及导出请求示例：

```json
{
  "issue_org_codes": ["发证机关代码"],
  "lic_no": "许可证号",
  "company_name": "客户名称关键词",
  "start_date": "2026-09-01",
  "end_date": "2026-09-30",
  "sort_field": "sysupdatedt",
  "sort_order": "descend",
  "page": 1,
  "page_size": 20
}
```

所有筛选可选，`{}` 表示全部当前不符记录。起止日期同时提供或同时省略；公司名称、许可证号、发证机关值均使用绑定参数。排序字段与方向由请求类型限制。非法输入返回 422，未登录返回 401。

行字段：`retailer_uuid / custbank_uuid / issue_org_code / issue_org_name / lic_no / company_name / manager_name / bankcard_owner / sysupdatedt`。两个 UUID 用于行标识和稳定排序；绑定时间为 `YYYY-MM-DD HH:mm:ss`。
