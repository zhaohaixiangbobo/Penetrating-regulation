# 03 · 前端 · 页面与路由

## 路由映射

| 路径 | 名称 | 说明 |
| ---- | ---- | ---- |
| `/user/login` | 登录 | 玻璃拟态卡片；`layout: false` |
| `/audit/short-visit` | 短拜访记录 | 功能 1 |
| `/audit/full-cust-miss` | 全商品缺访客户 | 功能 2 |
| `/audit/daily-under-hour` | 日拜访不足 60 分钟 | 功能 3 |
| `/dashboard` | 数据看板 | 占位「敬请期待」 |
| `/` | 重定向 | `/audit/short-visit` |

## 关键运行时（`src/app.tsx`）

- `getInitialState`：无 token → 跳登录；有 token → 调 `/api/auth/me`
- `request`：拦截器统一注入 `Authorization`，`errorHandler` 处理 401 跳登录
- `layout`：顶栏展示用户名 + 退出按钮

## 页面统一结构

- 顶部：`ProForm.QueryFilter`（公司下拉 + 时间/月份范围）
- 中部：`ProTable`，服务端分页，`request` 调对应 service
- 功能 2 页面顶部有 `Alert` 提示最早可查月份为 2025-02

## Service 目录

- `src/services/auth.ts` — `login / getMe / listCompanies`
- `src/services/audit.ts` — `queryShortVisit / queryFullCustMiss / queryDailyUnderHour`

## 组件

- `src/components/CompanySelect.tsx` — 公司下拉，首次加载调用 `/api/meta/companies`

## 本地 Mock

`frontend/mock/api.ts` 提供最小假数据；开发模式默认开启，可覆盖真实 API 便于 UI 走查。

## Token 存储

`localStorage.shenji_token`；退出登录时移除，401 时自动移除。
