# 03 · 前端 · 页面与路由

## 路由映射

| 路径 | 名称 | 说明 |
| ---- | ---- | ---- |
| `/user/login` | 登录 | 玻璃拟态卡片；`layout: false` |
| `/audit/short-visit` | 短拜访记录 | 功能 1 |
| `/audit/full-cust-miss` | 全商品缺访客户 | 功能 2 |
| `/audit/daily-under-hour` | 日拜访不足 60 分钟 | 功能 3 |
| `/audit/long-visit` | 单次超长拜访 | 功能 4：单条有效拜访超过所选阈值，默认 300 分钟 |
| `/audit/auto-collect-miss` | 自动信息采集户缺访 | 功能 5：评价生效月零有效拜访次数 |
| `/marketing-monopoly` | 营销专卖 | 与营销审计并列；重定向到扣款户名不符 |
| `/marketing-monopoly/bank-owner-mismatch` | 扣款户名不符 | 最新绑卡户名与有效许可证持证人比对 |
| `/dashboard` | 数据看板 | 占位「敬请期待」 |
| `/` | 重定向 | `/audit/short-visit` |

## 关键运行时（`src/app.tsx`）

- `getInitialState`：无 token → 跳登录；有 token → 调 `/api/auth/me`
- `request`：拦截器统一注入 `Authorization`，`errorHandler` 处理 401 跳登录
- `layout`：顶栏展示用户名 + 退出按钮

## 页面统一结构

- 顶部：`ProForm.QueryFilter`（公司下拉 + 时间/月份范围）
- 中部：`ProTable`，服务端分页，`request` 调对应 service
- 功能 2 页面顶部有 `Alert` 提示最早可查月份为 2025-02

## Service 目录

- `src/services/auth.ts` — `login / getMe / listCompanies`
- `src/services/audit.ts` — `queryShortVisit / queryFullCustMiss / queryDailyUnderHour`

## 组件

- `src/components/CompanySelect.tsx` — 公司下拉，首次加载调用 `/api/meta/companies`

## 本地 Mock

`frontend/mock/api.ts` 提供最小假数据；开发模式默认开启，可覆盖真实 API 便于 UI 走查。

## Token 存储

`localStorage.shenji_token`；退出登录时移除，401 时自动移除。

## 新增查询页的复用方式（2026-09-30）

两个新增页面均位于“营销审计”菜单下，复用 `src/pages/Audit/components/AuditQueryPage.tsx`。

- `LongVisit/index.tsx`：日期范围、最早 2024-01-01；展示公司、营业部、经理、客户、日期与分钟时长。日期和时长支持服务端排序；时长阈值可选 260、280、300、320、340 分钟，默认 300，查询、导出及缓存共用已提交阈值，重置恢复默认值。
- `AutoCollectMiss/index.tsx`：月份范围、默认上月、最早 2025-09；展示月份、公司、营业部、经理、客户编码和名称，支持月份排序。
- 公司多选/全选/清空，营业部和经理联动；部门及经理筛选在后端生效，经理采用 UUID。
- 共用页管理已提交条件，查询回第一页，重置清空条件和结果，保留当前表格排序。
- 字典请求通过请求序号处理快速切换公司；重新提交或重置后，之前的查询结果不会写入缓存。
- 仅缓存第一页，1 小时有效；缓存包含已提交筛选、排序、每页条数，使用查询版本和用户名隔离。
- 缓存键前缀分别为 `shenji_long_visit_v2`、`shenji_auto_collect_miss_v1`。
- 查询保留表格加载状态，导出显示加载状态；沿用公司标签配色、可复制字段和 Excel 导出工具。
- Excel 使用已提交条件和当前排序；达到 100000 行上限时提示缩小范围。月份显示为 `YYYY-MM`，超长拜访分钟数显示两位小数。

当前 `.umirc.ts` 配置为 `mock: false`，联调使用真实 API。后续同类查询可参考共用页及 [审计查询页面开发模板](11-审计查询页面开发模板.md)。

## 营销专卖模块

一级菜单“营销专卖”位于“营销审计”之后，子页面为“扣款户名不符”。页面位于 `src/pages/MarketingMonopoly/BankOwnerMismatch/index.tsx`，服务层为 `src/services/marketingMonopoly.ts`。

支持发证机关多选、许可证号精确查询、客户名称包含查询及可选绑定日期。进入页面后点击查询加载当前异常；复用表格、分页、用户缓存和 Excel 风格，详细口径及验收见 [模块说明](12-营销专卖-扣款户名不符.md)。
