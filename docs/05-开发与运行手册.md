# 05 · 开发与运行手册

## 环境要求

- Python：`D:\3-anaconda\envs\py312\python.exe` (Python 3.12)
- Node：v20.15.0 / npm 10.7.0
- 磁盘：项目位于 D 盘，不动 C 盘

## 后端

### 首次安装

```powershell
cd d:\2-code\shenji\backend
copy .env.example .env  # 按需修改 JWT_SECRET
D:\3-anaconda\envs\py312\python.exe -m pip install -r requirements.txt
D:\3-anaconda\envs\py312\python.exe -m scripts.init_db
```

### 启动

```powershell
D:\3-anaconda\envs\py312\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

- Swagger：<http://127.0.0.1:8000/docs>
- Redoc：<http://127.0.0.1:8000/redoc>

### 常用脚本

- `scripts/init_db.py`：建 SQLite 表 + 写入默认管理员
- `scripts/smoke_starrocks.py`：`SELECT 1` 连通性测试（手动）

## 前端

### 首次安装

```powershell
cd d:\2-code\shenji\frontend
npm install
```

`node_modules/` 位于项目内（D 盘），不占用 C 盘。

### 启动

```powershell
npm run dev
```

Umi 默认监听 `http://localhost:8000`；`.umirc.ts` 里已配置 `/api` 代理到 `http://127.0.0.1:8000`。

> 注意：若前端与后端端口冲突，前端启动时用 `PORT=3000 npm run dev` 切换端口。

### 生产构建

```powershell
npm run build
```

产物在 `dist/`，可用任意静态服务托管；建议同域反代 `/api` 到后端。

## 常见问题

- **前端拉不到 API**：检查 `.umirc.ts` 的 `proxy.target` 是否指向后端；或 CORS_ORIGINS 是否包含前端 origin。
- **登录成功但页面 401 循环**：确认后端 `JWT_SECRET` 未在启动之间变动。
- **StarRocks 连不上**：先跑 `python -m scripts.smoke_starrocks`，看具体错误。
