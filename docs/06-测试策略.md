# 06 · 测试策略

## 后端

- 框架：`pytest` + `pytest-asyncio` + `httpx.AsyncClient`（基于 ASGITransport 直接调用 FastAPI 应用）
- 独立 SQLite：`conftest.py` 在导入 app 前用临时目录覆盖 `SQLITE_URL`，避免污染 `data/app.db`
- StarRocks 不真连：`tests/test_audit.py` 通过 `app.dependency_overrides[get_starrocks_session]` 注入 `FakeSession`，断言：
  - SQL 参数正确绑定（`com_id / start_date / limit / offset`）
  - 功能 3 的秒→分钟转换：`1830 → 30.5`，`100 → 1.67`
  - 分页信息返回准确

### 运行

```powershell
cd d:\2-code\shenji\backend
D:\3-anaconda\envs\py312\python.exe -m pytest -q
```

### 用例清单

- `test_auth.py`：登录成功/失败、`/me` 鉴权、bad token、`/meta/companies` 鉴权、公司字典数量
- `test_audit.py`：非法 `com_id`、日期越界、月份越界、参数绑定、分钟换算、未登录 401

## 前端

- 必须通过：`npm run build`（Umi 4 使用 Vite/webpack 编译）
- 联调可开启 `mock/api.ts` 提供的假数据
