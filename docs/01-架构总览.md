## 逻辑架构

```
浏览器 ──► UmiJS 前端 (localhost:8000)
              │  Bearer <token>
              ▼
        FastAPI (127.0.0.1:8000)
              │
     ┌────────┴────────┐
     │                 │
   SQLite            StarRocks
  (账号存储)         (业务查询)
```

## 数据流

1. 前端登录页 POST `/api/auth/login`，后端查 SQLite `users` 表，校验密码，签发 JWT
2. 前端把 token 存 `localStorage.shenji_token`；每次请求自动带 `Authorization: Bearer <token>`
3. 业务查询接口带 JWT 依赖，解析成功后透传参数到 SQLAlchemy async → StarRocks
4. 查询 SQL 全部使用 `text().bindparams()` 参数化，`com_id` 白名单双重校验，杜绝注入
